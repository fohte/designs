# 再開後に起動しないとき

終わったセッションで Resume を押しても、エージェントが起動しないことがある (pane がフォルダーを信頼するかの確認などで止まる)。サーバーは起動したかを見ておらず、35 秒たつと何も言わずに This session has ended に戻っていた。pane の画面は PC では端末を開かないと見られず、iPhone では見る手段がなかった。

どの案でも、Resume から 20 秒たってもエージェントから返事がなければ、帯を黄色の Session hasn't started に替え、Retry と Close session (PC は Open in terminal も) を出す。

## 案

止まっている pane の画面の出し方:

- A: 20 秒たつと、会話の最後に pane の画面がそのまま出る。
- B: 帯の Show pane で、帯の中に画面を開く。画面は返信欄の位置に開き、ボタンは Hide pane に変わる。会話をスクロールしても画面は動かない。
- C: 帯の Show pane で、ダイアログ (iPhone はシート) を開く。中に画面、Retry、Close session、Done を置く。

pane の画面の更新:

- A: 開いている間、2 秒ごとに撮り直す。見出しの右に青い点と Live · every 2 s を出す。
- B: 開いたときに 1 回撮り、Refresh で撮り直す。撮った時刻と Refresh を出す。

## 採用した案

出し方は B (帯の中に開く)、更新は A (2 秒ごとに撮り直す)。

## 理由

- 帯の中に開けば、画面を見ながらその場で Retry を押せる。会話の列にメッセージでないものを足さず、ダイアログのように開くのと閉じるので 2 回押すこともない。
- 2 秒ごとに撮り直せば、端末で確認に答えた結果がすぐ画面に出る。tmux を呼ぶのは画面を開いている間だけになる。
