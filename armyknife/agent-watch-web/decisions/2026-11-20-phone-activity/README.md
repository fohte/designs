# iPhone の Activity の置き場所

iPhone では Activity の入り口が Inbox のヘッダーと会話のヘッダーの 2 か所にあり、ナビゲーションにはなかった。PC ではナビの quota の上にだけある。

## 案

- A: ナビゲーションにだけ置く (PC と同じ)。
- B: Inbox のヘッダーにだけ置く。
- C: 今のまま、Inbox と会話の両方のヘッダーに置く。

## 採用した案

A。ナビゲーションの quota の上に置き、実行中を青、失敗を赤の数で示す。開くと一覧をシートで出す。失敗があるあいだは Inbox のナビゲーションのボタンに赤い印を付ける。

## 理由

- PC と置き場所がそろう。
- 同じ入口が 2 か所にあった。
- 実行中や失敗はトーストと会話の 1 行で気付ける。
- 案の canvas は作っていないので、`project/` はない。
