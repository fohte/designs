# Markdown の折りたたみ (details)

会話、to-do、proposal、PR draft の Preview のどこでも、`<details>` と `<summary>` がタグの文字のまま出て、中身も常に見えていた。4 か所で同じ見た目にする。

どの案も、長い要約は省略せず折り返し、入れ子は同じ形を重ね、開いた状態はページを開いている間だけ保つ。

## 案

- A: GitHub と同じく、本文と同じ文字の行の左に ▸ を付ける。開くと ▾ になり、中身は字下げせずに続く。
- B: ツールの行と同じ小さな灰色の行にし、右に › を付ける。開くと ⌄ になり、中身は左の細い線の内側に字下げして出る。
- C: 枠で囲んだ箱にし、太字の要約の右に ⌄ を付ける。

## 採用した案

A。

## 理由

- PR draft の Preview と実際の PR の見た目がずれない。
- 枠が重ならず、ツールの行や Show less とも見分けられる。
