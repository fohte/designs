# セッションの vibe mode を切り替えて見せる

vibe mode が on のセッションは、PR を merge でき、人のレビューを待たずに submit できる。これまでは watch-web から切り替えられず、どの画面にも出ていなかった。親のセッションから引き継いで on になっていることや、repo の設定で使えないことも、画面からは分からなかった。

## 案

- A: タイトルの横にスイッチを置く。スイッチはこのセッションの設定だけを表し、on にするときだけ確認ダイアログを出す。
- B: タイトルの横に今の状態のボタンを置く。押すと理由と送るメッセージが出て、そこで切り替える。
- C: タイトルの編集欄で、タイトルと一緒に切り替える。ふだんのヘッダーには on のときだけ出す。

## 採用した案

B。セッションのページのヘッダーで、タイトルの横に Vibe on、Vibe on · inherited、Vibe off、Vibe unavailable のどれかを出す。押すと、理由、セッションに送るメッセージ、切り替えるボタンが出る。使えないときは理由と Close だけを出す。切り替えると、そのメッセージをセッションへ自動で送る。スマホではヘッダーの下に 1 行の帯を置き、押すと同じ中身のシートが出る。セッションの一覧の行では、on のときタイトルの後ろに稲妻のアイコンを出す。親から引き継いだ on は線だけで描く。

## 理由

- 引き継ぎで on になっていることや、使えない理由を、切り替える前に読める。
- 送るメッセージを見てから送れるので、別の確認ダイアログが要らない。
- A のスイッチは、引き継ぎで on のときも off に見え、文字を読まないと分からない。
- C は切り替えに 3 回押す必要があり、使えないことも編集欄を開くまで分からない。
