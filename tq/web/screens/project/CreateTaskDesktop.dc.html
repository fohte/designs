Title shortcuts

Type a token followed by a space to apply it.

@

Set a due date

@today@tomorrow
>

Set a start date

>today>YYYY-MM-DD
#

Add a label

#label
%

Set the work or personal context

%work%personal
^

Set a parent task by its number

^123
*

Set a recurrence rule

*daily*mon
!

Add the task to a planning period

!today!week
