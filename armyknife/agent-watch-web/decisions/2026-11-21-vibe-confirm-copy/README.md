# vibe mode の確認に出す送信文

vibe mode を切り替える確認 (PC のポップオーバー、iPhone のシート) には、見出し・説明・ボタンのほかに「Sent to the session」として、切り替えたときにセッションへ送る文面をそのまま出していた。ユーザーにとって、送る文面は切り替えるかどうかの判断に要らない。

## 案

- 送る文面を残す (今のまま)
- 送る文面をなくし、ボタンからも `and send` を外す

## 採用した案

送る文面をなくし、ボタンからも `and send` を外す。

- PC と iPhone の vibe mode の確認から、「Sent to the session」と送る文面をなくした。
- ボタンを `Turn on and send` から `Turn on` のようにした。
- 見出しと、切り替えると何が起きるかの説明は変えていない。
- ConfirmDialog から送る文面を出す部分 (quote) をなくした。使っていたのは vibe mode の確認だけで、Merge、閉じる前、! コマンドの確認は変わらない。

## 理由

- 切り替えるかどうかは、説明にある「何が起きるか」で決められる。送る文面には、状態によって説明にない内容 (引き継ぎで有効のまま残ることなど) も入るが、それはセッションに向けた指示で、切り替える人の判断には使わない。
- セッションに送ることは切り替えた結果であって、押す人が選ぶものではないので、ボタン名にも出さない。

選択肢を比べる explore の canvas は作らずに screens を直接変えたので、`project/` は残していない。
