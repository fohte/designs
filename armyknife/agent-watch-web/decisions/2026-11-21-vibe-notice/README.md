# vibe mode の切り替えを会話でイベントとして出す

vibe mode を on や off にすると、セッションにそのことを知らせるメッセージが送られる。会話ではこのメッセージが You の吹き出しで出ていて、ユーザーが自分で書いたように見えていた。

## 決めたこと

vibe mode の切り替えは、会話の中央に 1 行のイベントとして出す。文言は「Vibe mode turned on · 時刻」と「Vibe mode turned off · 時刻」。PC と iPhone で同じにする。会話に出るメッセージの Events に on と off を足し、返信欄の外で行ってセッションに伝わる操作はイベントとして出すと書いた。確認のダイアログとシートは変えていない。

案を比べずに screens を直接変えたので、`project/` は残していない。

## 理由

- 返信欄の外での出来事 (Session resumed など) は会話の中央に 1 行のイベントとして出ていて、アプリでは To-do の完了や Decision の変更の知らせも同じイベントとして出している。vibe mode の切り替えも同じ操作の知らせなので、同じ見え方にそろえる。
- You の吹き出しは、ユーザーが返信欄から書いたメッセージだけに使う。
