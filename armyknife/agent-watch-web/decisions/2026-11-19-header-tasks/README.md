# 会話のヘッダーの tq タスク

会話のヘッダーには、主の tq タスクの右に +N tasks ▾ があり、開くとポップオーバーでタスクの一覧と Make primary を出していた。同じ一覧と Make primary は状況パネルの Tasks にもあり、操作の置き場所が 2 つあった。

## 案

- A: ヘッダーには主タスクの名前だけを残す。ほかのタスクは状況パネルの Tasks で見る。
- B: A に加えて、主タスクの右に +N を出す。押すとポップオーバーではなく状況パネルの Tasks を開く。
- C: ヘッダーから tq タスクをなくし、状況パネルの Tasks だけで見る。

どの案でも、ポップオーバーはなくし、Make primary は状況パネルの Tasks だけで行う。

## 採用した案

B。ヘッダーには主タスクを出し、ほかにもタスクがあるときは右に +N を出す。+N を押すと状況パネルの Tasks を開き、主でないタスクを強調する。Tasks では各タスクの右に Primary か Make primary を出す。

## 理由

- 何のタスクの会話かが、ヘッダーで分かる。
- ほかにもタスクがあることが、ヘッダーで分かる。
- 一覧と Make primary の置き場所が状況パネルの Tasks だけになる。
- iPhone の会話のヘッダーには、もともと tq タスクを出していない。
