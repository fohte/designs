# 確認したあと裏で実行する操作の結果の見せ方

Merge やセッションを閉じる操作では、確認のダイアログで確定しても、終わるまでダイアログが開いたままだった。そのあいだはほかの操作ができず、別のセッションへ移ることもできなかった。

## 案

- A: 確定したらダイアログを閉じ、トーストで実行中・成功・失敗を知らせる。失敗のトーストには Retry と Details を付ける。
- B: 押した場所 (Merge のボタン、Inbox の行) を Merging… や Closing… に変え、終わったら結果に変える。
- C: ナビの Activity (スマホはヘッダー) にバッジと一覧を出し、実行中と結果をあとから見返せるようにする。会話にも結果を 1 行残す。

## 採用した案

A、B、C をすべて使う。確定したらダイアログをすぐ閉じて裏で実行する。押した場所で実行中と結果を見せ、トーストでも知らせ、Activity と会話に結果を残す。

## 理由

- 押した場所を見ていれば、そこで結果が分かる。
- 別のセッションへ移ったときや、閉じたセッションが Inbox から消えたときも、トーストで結果に気づける。
- あとから Activity と会話で結果を見返せる。
- 案の canvas は古い画面をもとに描いていて、Merge の位置や quota の表示が今の画面と違う。screens には今の画面に合わせて反映した。
