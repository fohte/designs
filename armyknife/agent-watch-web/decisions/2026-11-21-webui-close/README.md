# 全画面の web UI を閉じる

iPhone で会話の web UI のリンクから全画面で開いた web UI は、左上の ‹ で会話に戻っていた。前は右上の × で閉じていて、左上の ‹ は閉じる操作だと気づかれなかった。

## 案

- A: ‹ をやめて、右上に ↗ と × を並べる。
- B: ‹ を残し、右上に × も足す。

## 採用した案

A。全画面の web UI のヘッダーから ‹ をなくし、名前と URL を左に、右上に ↗ (新しいタブで開く) と × (閉じる) を並べる。× で会話に戻る。状況パネルの ‹ は変えない。

## 理由

- 前と同じく右上の × で閉じられる。
- 状況パネルの web UI のバーと同じ ↗ × の並びになる。
- B は ‹ と × が同じ動きでボタンが 1 つ余り、名前と URL の幅も狭くなる。
- 左上で戻る iPhone の習慣に合わないことは受け入れる。
