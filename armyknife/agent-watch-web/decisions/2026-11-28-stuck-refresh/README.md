# 止まった pane の画面の更新

Session hasn't started の帯で Show pane を押すと、帯の中に tmux の pane の画面を開く。開いている間はサーバーが 2 秒ごとに撮り直し、見出しの右に Live · every 2 s を出していた。この方法では、画面を開いている間はずっと tmux を呼び続ける。

## 案

- A: 見出しの右に撮った時刻 Updated 14:40:22 (iPhone は 14:40:22) と Refresh を置く。押すと新しい画面が届くまで前の画面を残し、ボタンを Refreshing… にする。
- B: 見出しの右に Refresh だけを置く。
- C: 見出しの右に Updates when the session changes (iPhone は Updates on change) と Refresh を置き、状態が変わると撮り直すことを示す。

## 採用した案

A。サーバーは Show pane で開いたとき、Refresh を押したとき、セッションの状態が変わった通知 (SSE) が届いたときに pane を撮り、撮り続けて流すことはしない。

## 理由

- 撮った時刻を出せば、見ている画面がいつのものかわかり、端末で答えたあとに Refresh が要るかを判断できる。B ではそれがわからない。
- 状態が変わったときに撮り直すことを文で約束しないので、通知が来ない変化 (確認の画面の中の選択など) でも表示が嘘にならない。
- 撮り続けないので、画面を開いたままでも tmux を呼び続けない。
