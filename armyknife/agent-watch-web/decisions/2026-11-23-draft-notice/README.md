# draft を開いていることを知らせる帯

draft がエディタで開いていても、返信欄の上の帯は Waiting とセッションのメモだけで、Review タブに読むものがあることに気付けなかった。

## 案

- A: crit と同じ黄色の Waiting for your review にし、draft の数と、エディタに出ている draft の種類と対象 (例: 4 drafts · Issue comment #412 is in the editor) を出す。Open drafts で Review タブを開く。
- 今のまま Waiting にする。

## 採用した案

A。

## 理由

- crit のレビュー待ちと同じ見た目になり、自分が読む番だと分かる。
- Open drafts から 1 回で Review タブを開ける。
