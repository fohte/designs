# セッションの起動

watch-web から、任意のディレクトリで Claude Code か Codex のセッションを起動する入口を決めた。

## 案

- A: サイドバーの + から、ディレクトリ、engine、worktree、最初のメッセージを 1 つのフォームで入れる
- B: ⌘K のコマンドパレットで New session を選び、ディレクトリを選んで Enter で起動する
- C: サイドバーの project の行の + から空の会話を開き、入力欄で設定を選ぶ
- D: サイドバーの ⌘K の横の + から空の会話を開き、ディレクトリは後から選ぶ

## 決めたこと

B と D の両方を入れる。

- B はユーザーが確定とした。
- C の「空の会話から始める」形はユーザーが採りたいとした。ただし、入口をサイドバーの project の行に置くのはやめ、⌘K の横に + を置いて、ディレクトリは後から選ぶ形にするよう求めた。これを D とした。
- スマホでは、Inbox のヘッダーの検索ボタンの前に + を置く。
