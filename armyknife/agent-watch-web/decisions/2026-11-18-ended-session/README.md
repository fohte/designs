# 終わったセッションの返信欄を見せる

終わったセッションを開くと、返信欄は押せないのに、見た目も placeholder (Message session) も動いているセッションと同じだった。なぜ書けないのか、続けたいときにどうすればよいのかが分からない。

## 案

- current: 今の返信欄。disabled なだけで見た目は変わらない。
- A: 返信欄を「This session has ended」の帯と Resume ボタンに替える。押すと再開し、返信欄が戻る。
- B: 返信欄は使えるままにし、上に「Ended · 送ると再開する」と出す。送るボタンは Resume and send にし、送ると再開してから届ける。
- C: 返信欄を A と同じ帯と New session here ボタンに替え、同じディレクトリで新しいセッションを始める。

## 採用した案

A。返信欄と状態の帯の代わりに、灰色の四角、This session has ended、終わった時刻の帯を出す。PC では帯の右に Resume、スマホでは帯の下に幅いっぱいの Resume session を置く。押すと Resuming… になって押せなくなり、再開したら今の返信欄と状態の帯に戻る。下のモデルと使用量の行は残す。

## 理由

- A は終わったことがいちばんはっきりし、押すまで何も起きない。
- B は手数が動いているセッションと同じだが、送るボタンの文字が変わるだけなので、気づかずに再開しうる。再開に失敗したときに書いた文をどうするかも決める必要がある。
- C は再開の仕組みが要らないが、会話の続きにならず文脈を引き継げない。
