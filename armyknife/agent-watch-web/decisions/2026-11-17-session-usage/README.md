# セッションの使用状況と quota を出す

ターミナルの status line には model、effort、context の使用量、quota、バージョンが出るが、watch-web にはどれも出ていなかった。Codex のセッションでも同じ情報を見たい。quota は engine ごとに、どの画面からでも見たい。

## 案

セッションのページの使用状況の行と、サイドバーの quota を別々に選ぶ形にした。

- A: 使用状況の行をヘッダーのタイトルの下に置く。
- C: 使用状況の行を返信欄の下に置く。ターミナルの status line と同じ場所。
- X: サイドバーの一番下に、engine ごとに 5h と 7d の棒を出し、リセットまでの時間も出す。
- Y: サイドバーの一番下に、engine ごとに 1 行で数字だけを出す。

使用状況の行から開く詳細 (Detail) も描いたが、ユーザーは要らないとした。

## 採用した案

C + X。返信欄の下に、engine、model (effort)、context の使用量、5h と 7d の quota、バージョンを 1 行で出す。幅が足りないときは折り返す。サイドバーとスマホのドロワーの一番下には、engine ごとの quota の棒を常に出す。棒の細い縦線は、均等に使ったときに今までに使っているはずの量で、それを超えると ▲、下回ると ✓ を出す。

## 理由

- 使用状況の行は、ターミナルの status line と同じ場所にあると見つけやすい。ヘッダーの高さも変わらない。
- quota は残りとペースを棒の長さで読めるほうが、数字だけより早く判断できる。リセットまでの時間がスマホでも見られる。
