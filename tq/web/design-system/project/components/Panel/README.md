# Panel

A bordered box for grouped content, from `@fohte/ui/panel`: one `border` hairline, no fill, square.

- The consumer supplies the children and `padding`: `md` (12px, default), `sm` (6px × 12px) or `none` when the rows carry their own padding and dividers.
- Rows inside a `none` panel separate with a `border` bottom line, the last row without one.
