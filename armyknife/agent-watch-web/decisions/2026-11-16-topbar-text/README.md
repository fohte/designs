# モバイルのトップバーの文字が切れる問題

モバイルの会話画面のトップバーでは、タイトルの下の段にタスク名、完了件数、repo を 1 行に並べていて、幅が足りずにほとんど読めなかった。

## 案

最初の案 A-C は、Paused や完了件数のチップを残したまま並べ方を変える案だった。

- A: 2 段目を画面の幅いっぱいに広げ、タスク、完了件数、repo を並べる。
- B: トップバーはタイトルだけにし、タスクは状況パネルで見る。
- C: タイトルを 2 行まで折り返し、その下にタスクの段を置く。

ユーザーは、2 段にしても文字が長くて切れること、Paused は表示によって操作が変わらないので PC でも出さなくてよいことを指摘した。そのあと、2 段目に何を出すかの案として D-F を作った。

- D: 2 段目はタスクだけ。repo と完了件数は状況パネルで見る。
- E: 2 段目は短いものだけ (repo · タスク番号 · +12 done ▾)。タスク名は状況パネルで見る。
- F: 2 段目はタスクと repo。長いときはタスク名の末尾を省略する。

## 採用した案

F。2 段目は画面の幅いっぱいを使い、タスク名と repo だけを出す。完了したタスクの一覧は、状況パネルに足した Tasks タブで見る。Paused はどこにも出さない。

## 理由

- タスクと repo を一度に見られる。
- 完了件数を 2 段目から外すと、タスク名に使える幅が増える。
- 完了したタスクの一覧は、ユーザーが状況パネルに置くことを選んだ。
