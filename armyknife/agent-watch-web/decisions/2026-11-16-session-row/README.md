# セッションの行を全一覧で共通にする

Inbox、サイドバーの Starred / Recent / PM、ボード、⌘K、状況パネルの tree、スマホの Inbox とドロワーは、セッションをそれぞれ別の見た目で並べていた。種類を文字で出す一覧や tq タスクの番号だけを出す一覧があり、role と engine はどこにも出ていなかった。

## 案

どちらも、すべての一覧を同じ 1 つの行で描く。Inbox とスマホの Inbox はプレビューを含む full、それ以外は compact にする。

- A: 先頭に状態 (種類のアイコン、Working の青い丸、Done の ✓) を置き、role のアイコンと engine は 3 行目の頭に灰色で出す。
- B: 先頭に role の色付きのアイコンを置き、種類のアイコンと文字は経過時間の横に出す。

案を見たユーザーは、次のことを指摘した。

- 種類は実装と同じアイコンで出す。
- tq タスクは番号だけでは分からないので、タイトルも出す。
- compact でも tq タスクと repo を省かず、3 行使ってよい。
- starred の印は各行に要らない。
- role がないセッションにも印を出し、role のあるセッションとタイトルの位置をそろえる。

## 採用した案

A。どの一覧でも 1 行目はタイトルと経過時間、2 行目は full ではプレビュー、残りの行は role のアイコン、engine (`claude` / `codex` の文字)、tq タスクの番号とタイトル、repo を出す。role がないセッションには、灰色の … (ellipsis) を出す。サイドバーの PM は、プロジェクトの一覧から PM のセッションの一覧に変えた。スマホでは PM のセッションをドロワーにだけ出し、Inbox には出さない。

## 理由

- 一覧を見る目的は、手を入れるべきセッションを探すことなので、状態を先頭に置く。
- role と engine は、状態の次に見る補足として灰色で控えめに出す。
- engine はロゴを使わず文字で出す。Anthropic と OpenAI のロゴは商標で、使うには事前の許可が要る ([Anthropic](https://www.anthropic.com/legal/trademark-guidelines)、[OpenAI](https://openai.com/brand/))。
