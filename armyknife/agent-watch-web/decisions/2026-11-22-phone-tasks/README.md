# iPhone の会話のトップバーの tq タスク

iPhone の会話のトップバーは、タイトルの下の行に主の tq タスクだけを出していた。セッションにほかのタスクがあることも、その一覧への入り方もなかった。PC のヘッダーは主タスクの右に +N を出し、押すと状況パネルの Tasks を開く。

## 案

- A: 主タスクの行の右に枠つきの +N。押すと Tasks の下からのシートを開く。
- B: トップバーに件数つきの Tasks ボタンを置く。押すと A と同じシートを開く。
- C: トップバーは変えず、⋯ のメニューの Tasks からシートを開く。
- D: PC と同じ。主タスクの右に枠のない +N を出し、押すと状況パネルを全画面で開いて Tasks を選ぶ。

## 採用した案

D。ほかにもタスクがあるときは、主タスクの右に PC のヘッダーと同じ灰色の枠のない +N を出す。+N を押すと状況パネルを開いて Tasks を選び、主でないタスクを強調する。Tasks では各タスクの右に Primary か Make primary を出す。

## 理由

- 見た目と動きが PC と同じで、覚えることが増えない。
- 一覧と Make primary の置き場所が、PC と同じく状況パネルの Tasks だけになる。シートを新しく作らない。
- 全画面の状況パネルに切り替わり、会話に戻るのに ‹ が 1 回要ることは受け入れる。
