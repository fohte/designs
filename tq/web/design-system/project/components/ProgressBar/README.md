# ProgressBar

A 2px progress line (`web/src/components/ui/progress-bar.tsx`): a `surface-strong` track with a fill clamped to 0–100%.

- The consumer supplies `percent` and `tone`: `foreground` (default) or `muted` (`muted-foreground` fill).
- Used for project progress in the projects list (the 190px column) and the project sidebar.
