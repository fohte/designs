# スマホで vibe を 1 行使わずに出す

スマホの会話のヘッダーでは、vibe mode の状態をヘッダーの下の 1 行 (36px) の帯で出していた。帯が会話の表示を狭めていた。

## 案

- A: 右上のボタンの並びに、稲妻のアイコンボタンを入れる。
- B: タスクとディレクトリの行の右端に、小さな Vibe の印を置く。
- C: ヘッダーにはボタンを置かず、… のメニューから切り替える。on のときだけタイトルの後ろに稲妻を出す。

## 採用した案

C。スマホの会話のヘッダーから vibe の帯をなくす。vibe が on のときだけ、タイトルの後ろに稲妻を出す。親から引き継いだ on は線だけで描く。… のメニューの先頭に「Vibe mode」と今の状態を出し、押すと今までと同じシートが開く。PC のヘッダーは変えない。

## 理由

- ヘッダーが 36px 低くなり、右上のボタンも増えない。
- タイトルの後ろの稲妻は、セッションの一覧の行と同じ見え方になる。
- A は右上のボタンが増え、タイトルが狭くなる。
- B は印が小さく、押せることが伝わりにくい。
