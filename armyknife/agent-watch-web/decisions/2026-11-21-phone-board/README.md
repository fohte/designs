# iPhone の Board

PC の Board はプロジェクトごとの列を横に並べて見せるが、iPhone には Board がなかった。ナビゲーションには Inbox / Board の切り替えがあり、Board を選んだときの画面が必要だった。

## 案

- A: プロジェクトのタブを並べ、1 列ずつ画面の幅いっぱいに見せる。
- B: 列をプロジェクトの見出しにして、1 本の縦リストにする。
- C: 幅 300px の列を横に並べ、横に送って見る。右に次の列の端が見える。

どの案でも、列の中は PC と同じく Needs action → In progress → ✓ Done で、行は iPhone の Inbox と同じ大きさにする。

## 採用した案

C。PC の Board の列を幅 300px にして横に並べ、横に送って次の列を見る。右に次の列の端を見せ、上の点で今どの列かを示す。ナビゲーションの Inbox / Board の切り替えから開く。

## 理由

- PC の Board と並びも見た目もいちばん近く、同じものとして見られる。
- 右に次の列の端が見え、まだ列があると分かる。
- 一度に全部が見えるのは 1 列だけで、列が狭くタスク名が切れやすいことは受け入れる。
- 列の中の縦スクロールと列を送る横スクロールが重なり、列名から目当てのプロジェクトへ飛べないことも受け入れる。
- A はタブを順に押さないと全体を見渡せず、プロジェクトが多いとタブがはみ出す。
- B は列が並ぶ感じがなくなり、Inbox との違いが薄い。下のプロジェクトの Needs action も遠くなる。
