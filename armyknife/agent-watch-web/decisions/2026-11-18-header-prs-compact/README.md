# 会話のヘッダーの PR ボタンを小さくする

スマホの会話のヘッダーで、PR のボタンが専用の行を取り、ヘッダーが約 131px になって画面を取りすぎる。

## 案

- current: 今の形。スマホはタイトルの下に PR の行 (44px) を置く。
- A: PR ボタンを見た目 28px に小さくし、タスクとディレクトリの行の右端に置く。ヘッダーは約 85px。
- B: PR をアイコンだけのボタンにして、右上のボタンの並びに入れる。ヘッダーは約 81px。

## 採用した案

B。スマホと PC の両方で、PR をアイコンだけのボタンにする。右上に CI の状態を表す点の色、右下に PR の数を出し、押すと今と同じ一覧を開く。PC では右上の「■ #2047 Open +1 ▾」を置き換える。

## 理由

- B はヘッダーが一番低く、スマホと PC で PR ボタンの形がそろう。
- A は番号と状態を文字で読めるが、ヘッダーが B より高く、PC との形もそろわない。
- B では番号と状態が一覧を開くまで見えないが、CI の状態は点の色で分かる。
