###session open

This machine's contextこのマシンの context。タスク・スケジュール・カレンダーの絞り込みと、他 context のセッション行を開けなくする判定に使われる
Focus URL template稼働中セッションを開くときに展開する URL。{sessionId} が実際の id に置き換わる。未設定なら claude --resume コマンドをコピーする
Resume URL template終了済みセッションを開き直すときに展開する URL。{sessionId} が実際の id に置き換わる。未設定なら claude --resume コマンドをコピーする
