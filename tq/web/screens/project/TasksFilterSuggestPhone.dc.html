Search syntax

Filters

is:
Filter by whether a task is todo or completed.
is:todo Todois:completed Completed
context:
Limit results to work or personal tasks.
context:work Workcontext:personal Personal
priority:
Limit tasks by priority value. Display names follow your priority settings.
priority:2 Nowpriority:1 Nextpriority:0 Normalpriority:none Inboxpriority:-1 Later
sort:
Sort results by date or configured priority. Repeat sort: to break ties with later keys.
sort:due Sort by due datesort:created Sort by creation datesort:updated Sort by update datesort:priority Sort by priority
has:
Filter by pages, comments, children, blockers, follow-up dates, or resolved waits.
has:pages Has pageshas:comments Has commentshas:no-children Has no childrenhas:blockers Has blockershas:no-blockers Has no blockershas:follow-up-due Has follow-up duehas:resolved-wait Has a resolved wait to acknowledge
label:<label>
Limit results to tasks with this label.
parent:<task-id-or-number|root>
Limit results to children of this task UUID or number, or use 'root' for tasks whose parent does not match the other filters.
project:<project-id>
Limit results to tasks in this project ID.
