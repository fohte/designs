# quota の着地予測の見せ方

v0.1.764 で、quota の窓の終わりに何 % になるか (使用率 ÷ 窓の経過率) をサイドバーと使用状況の行に出すようになった。ただ、記号が絵文字の ✓ ⚠ 🔥 で等幅の見た目から浮き、100% 未満でも ✓ 76% が本文と同じ明るさで目を引く。棒の細い縦線 (均等に使ったときの量) と予測の数字が別々のことを言っていて、どちらを見ればよいか分からない。

## 案

- current: 今の実装。✓ ⚠ 🔥 と予測の % を、リセットまでの時間の前に出す。
- A: 棒の使用量の先に、窓の終わりの着地点までを暗い色で伸ばす。数字は 100% 未満が → 76%、100% 以上は ▲ 119%。使用状況の行にも小さな棒を足す。
- B: 棒と縦線はそのまま。100% 未満は ✓ だけ、100% 以上のときだけ ▲ と予測の % を出す。
- C: 100% 以上のときは、予測の % の代わりに使い切るまでの時間 (▲ out 49m) を出す。
- D: 今の使用率 → 窓の終わりの予測 (7d 62% → 119%)。矢印と予測の数字を同じ色にし、ほかの記号は使わない。
- E: 予測にラベルを付ける (7d 62% · end 119%)。100% 以上では数字の後ろに警告アイコンを付ける。

## 採用した案

D。サイドバーは棒と縦線を残し、棒の右に → 119% とリセットまでの時間を出す。予測とリセットまでの時間は列の幅を決め、行ごとに位置を揃える。使用状況の行は 7d 62% → 119% の形で、5h と 7d の間を使用率と予測の間より広く空ける。

- 矢印と予測の数字の色: 100% 未満は灰 (#8b8b94)、100% 以上 150% 未満は黄 (#fbbf24)、150% 以上は赤 (#f87171) の太字。
- 窓の経過が 5% 未満では矢印も予測も出さない。
- hover と読み上げ: 7d: 62% used, projected 119% at window end, at or above quota pace, resets in 3d8h

## 理由

- 行の狭いところに棒を足すと、使用状況の行が長くなり読みにくい (A)。
- 使い切るまでの時間は status line の % と違う数字になり、リセットまでの時間も隠れる (C)。
- 裸の ▲ は減ったように読め、使用率の隣にあると何の数字か分かりにくい (B)。
- D は「今 → 窓の終わり」と 1 つの記号で読め、100% 未満の予測もスマホで見える。E のラベルとアイコンは D より長く、スマホで折り返しやすい。
