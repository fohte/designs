# 最初のメッセージに画像

新しいセッションの + の画面と ⌘K の New session では、最初のメッセージに画像を入れられなかった。+ の画面は複数行の欄だが画像を貼っても何も起きず、⌘K は 1 行の欄だった。会話の返信欄は画像を貼れるが、📎 はなく、画面に落としても受けなかった。

どの案でも、最初のメッセージの欄は会話の返信欄と同じ部品にし、会話の返信欄にも画像を選ぶボタンを付ける。ディレクトリを選ぶ前に貼った画像も残り、押せないのは Start だけ。

## 案

### 1-1. + の画面

- A: 1 つの箱に、上から文、画像、ボタンの列 (📎、engine、モデル、New worktree、Start) を並べる。
- B: engine・モデル・worktree のボタンを箱の上の 1 行に出し、箱は会話の返信欄と同じにする。
- C: 設定のボタンをヘッダーに移し、下には会話と同じ返信欄だけを置く。

B の iPhone をチャットアプリの入力欄に寄せて描き直し、角の形で 2 つに分けた。配置はどちらも同じで、箱の中に上からサムネイル (右上に ×)、文、下の行の左に +、右に送信。

- B1: 箱、サムネイル、チップ、+ と送信の角を丸くし、design-system の角も丸く直す。
- B2: 角は design-system どおり四角くする。

### 1-2. ⌘K

- A: 上の欄を複数行にし、画像はその下に並べる。候補の一覧はその下に押される。
- B: 候補の一覧を上に残し、返信欄と同じ箱を一覧の下に置く。
- C: ⌘K ではディレクトリだけ選び、↵ でディレクトリが入った + の画面に移って書く。

### 2. 画像を落とせる場所 (PC のみ)

- A: 返信欄の上に落としたときだけ受ける。
- B: 右側の画面のどこに落としても受ける。
- C: 落としても受けず、貼り付けと 📎 だけにする。

## 採用した案

- 1-1: B2。設定のボタンは箱の上の 1 行。新しいセッションでは送信が Start を兼ね、ディレクトリを選ぶ前は灰色で押せず、「Choose a directory to start」を箱の外の下に小さく出す。会話の返信欄も同じ箱にする。iPhone のボタンは 44px。
- 1-2: C を基本にし、A もできるようにする。
- 2: B。+ の画面でも会話でも、ファイルを持ってくると画面に点線が出る。

「新しいセッションの画面」で、+ の画面は ⌘K の New session と同じ 1 本の入力と一覧にすると決まった。そのため ⌘K で書く欄 (A) と、↵ で移った先の + の画面の欄 (C) は同じ形になる。

## 理由

- 1-1 B: 始めたあとも、同じ場所に同じ形の返信欄が残る。A は始めたあとに返信欄の形が変わり、C は設定が Start から遠い。
- 1-1 B2: design-system を変えずに B1 と同じ使い勝手になり、ほかの画面と角がそろう。B1 はこの欄のために design-system の見直しまで広げることになる。
- 1-1 の最初の B の iPhone は見た目が退けられたので、チャットアプリの配置に描き直した。
- 1-2 C: 最初のメッセージを書く場所が 1 つになり、複数行の欄で ⌥↵ や ↑↓ が改行やカーソル移動とぶつからない。A も残すのは、⌘K の中で書いてそのまま始められるようにするため。B は書く場所が一覧の下にあり、ディレクトリを選んだあと目が下へ動く。
- 2 B: 狙わずに落とせ、+ の画面と会話で同じ動きになる。A は小さな欄を狙う必要があり、C は Finder などからそのまま持ってこられない。
