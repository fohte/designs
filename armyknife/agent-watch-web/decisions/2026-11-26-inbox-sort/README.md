# Inbox の並べ替え

Inbox の見出しには「Sorted by tq priority」と出るだけで、並べ替えを選べなかった。iPhone には並び順の表示もなかった。

選べる並び順は Priority (既定。tq の優先度順、同じなら更新の新しい順)、Updated (更新の新しい順)、Project (project 名の順) の 3 つ。選んだものはブラウザごとに保存する。Needs action などの区分は変えず、区分の中の順だけが変わる。

## 案

選ぶ操作の形:

- A: 見出しの右の文字を「Sort Priority ⌄」のボタンにし、押すとメニューを開く。PC は Later と同じ形のメニュー、iPhone は下から出るシート。
- B: 見出しの右に Priority、Updated、Project の 3 つのボタンを並べる。
- C: 絞り込みの欄の右に「↕ Priority」のボタンを置く。

Project で並べたときの見た目:

- A: 小見出しは付けず、行の右の repo 名の順に並べるだけ。
- B: 各区分の中に project ごとの小見出しを入れる。

## 採用した案

操作は A、Project は B (小見出しを入れる)。

- メニューとシートでは、今の並び順に ✓ を付け、各選択肢に並べ方の説明を添える。
- 同じ project の中は Priority の順に並べる。

## 理由

- 今の文字の位置と、今あるメニューやシートの形をそのまま使え、幅も取らない。並び順はあまり変えないので、選び直すのに 1 回多く押すことは問題にならない。
- 小見出しがないと、行の右の小さな repo 名でしか順番が分からず、Project で並べたことが画面から読み取れない。
