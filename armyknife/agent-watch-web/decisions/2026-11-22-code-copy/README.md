# コードブロックのコピー

会話のメッセージの中のコードブロックには、コピーする手段がなかった。コピーするには長押しやドラッグで範囲を選ぶしかなく、横に長い行はブロックの中で横にスクロールしていた。

## 案

- A: どのブロックにも右上に、Copy session ID と同じ 26px のアイコンボタンを常に出す (iPhone は 44px)。押すと 1.5 秒チェックに変わる。ボタンはブロックの右端に自分の列を持つ。
- B: PC ではポインターが乗ったブロックにだけ A のボタンを出す。iPhone は hover がないので常に出す。
- C: ブロックの上に帯を置き、左に言語名 (ts、bash、text)、右に文字付きの Copy ボタンを出す。押すと 1.5 秒 ✓ Copied に変わる。

## 採用した案

C。帯の高さは PC で 30px、iPhone で 44px。帯はコードと一緒に横へスクロールしない。アシスタントのメッセージにも、自分のメッセージの吹き出しの中にも同じ帯を付ける。

## 理由

- iPhone では A と B のボタンがコードそのものにかぶっていた。C の帯はコードの上にあり、長い行を横にスクロールしてもコードに重ならない。
- 文字があるので何のボタンか迷わず、言語名も分かる。
- コードの幅が右の列の分だけ減ることがない。
- ブロックごとに帯の高さが増え、2 行ほどの短いコードでは帯が目立つことは受け入れる。
