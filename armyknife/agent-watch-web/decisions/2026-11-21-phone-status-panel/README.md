# iPhone の状況パネル

PC では会話の右に状況パネルを開き、Running / Tasks / Tree / Review / Decisions / crit のタブを切り替える。iPhone の会話のヘッダーには状況パネルを開くボタンがあったが、開いた先を描いていなかった。

## 案

- A: 会話の上に全画面のページを重ねる。ページには戻るボタンと「Session status」の見出しを置き、その下の横にスクロールするタブで切り替える。
- B: 会話の上に背の高いシートを出し、横にスクロールするタブで切り替える。
- C: タブを要約つきの一覧にして、押すとそのタブのページに進む。

## 採用した案

A。会話のヘッダーのボタンを押すと、会話の上に状況パネルのページを重ねる。戻るボタンで会話に戻る。タブは横にスクロールし、隠れたタブがある側の端をぼかす。

## 理由

- Review の編集欄と crit の web UI に、画面の高さをすべて使える。
- タブを 1 回押すだけで切り替えられる。C はタブを変えるたびに一覧へ戻る必要がある。
- 戻るボタンと見出しのページは、iPhone の新しいセッションの画面と同じ作りになる。
- 状況パネルを開いている間は会話が見えないこと、390px の幅ではタブが収まらず横にスクロールすることは受け入れる。
