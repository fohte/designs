# モバイルのセッション画面のトップバー

モバイルのセッション画面では、トップバーに要素が並びきらず、タイトルが潰れてボタンがはみ出していた。

## 案

- A: 2 段にする。1 段目にタイトルとタスク、2 段目に操作のボタンを並べる。
- B: 操作をメニューに入れる。トップバーには Later と ⋯ だけを残す。
- C: 操作を画面の下、入力欄の上に置く。

## 採用した案

B を変えたもの。トップバーの右端には ステータスパネル と ⋯ を置き、ほかの操作 (Later / Close / スター / ID コピー / タイトル編集) はすべて ⋯ のメニューに入れる。スター済みはタイトルの前の星で示す。

## 理由

- Later もメニューに入れると、トップバーのボタンが 2 つになり、タイトルの幅を確保できる。
- ステータスパネルはメニューに入れず、1 回のタップで開けるままにするとユーザーが決めた。
