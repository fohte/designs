# 複数の draft の切り替え

1 つのセッションが draft を複数開いていても、Review タブには 1 つしか出ず、ほかに draft があることも分からなかった。

## 案

- A: Review の下に draft ごとのタブを並べ、種類と対象を短く出す。エディタに出ているものに黄色の点、順番待ちに灰色の点を付け、Review タブに draft の数を出す。
- B: 1 / 4 と種類を出したボタンで一覧を開き、‹ › で前後に送る。iPhone は一覧と詳細の 2 画面。
- C: パネルは一覧だけにし、押すとパネルの中で開く。‹ Drafts で一覧に戻る。

## 採用した案

A。

## 理由

- 開いている draft が全部一目で見え、1 回押せば切り替わる。
- draft が多いとタブが狭くなる。1 つのセッションが同時に開く draft は数個と見込んでいるが、上限は確かめていない。
- サーバーが、開いている draft を全部返すように変える必要がある。
