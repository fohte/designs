# iPhone の会話のトップバー

iPhone の会話のヘッダーには、左に Inbox へ戻る ‹、右に PR、状況パネル、⋯ のボタンがあり、タイトルは 15px の 1 行で約 100px しか出なかった。会話からナビゲーションを開く手段もなかった。iPhone のブラウザでは画面の端からのスワイプがブラウザの戻る / 進むに取られるので、ナビゲーションは押せるボタンで開く必要がある。

## 案

どの案も ‹ を残し、その右にナビゲーションのドロワーを開く ☰ (44px) を足す。Activity はナビゲーションの中にあるので、Activity に失敗があるあいだは Inbox と同じく ☰ に赤い印を付ける。

- 右上を … だけにする: タイトルを押すと状況パネルを開き、PR はパネルの先頭の一覧から開く。
- タイトルを 2 段目に下ろす: ボタンの段と tq タスクの行のあいだに、タイトルだけの行を足す。
- タイトルを 2 行に折り返す: タイトルを 13px にして 2 行まで折り返す。PR のボタンをなくし、状況パネルのボタンに CI の点と数を出し、パネルの先頭に PR の一覧を足す。
- 右上を … だけにして、タイトルを 2 行に折り返す: 1 つ目と 3 つ目を合わせる。

## 採用した案

タイトルを 2 行に折り返す。

- 左に ‹ と ☰ を並べる。どちらも 44px。
- Activity に失敗があるあいだは ☰ に赤い印を付ける。
- タイトルは 13px の太字で 2 行まで折り返し、それより長いと … で切る。
- 右は状況パネルと ⋯ のボタンにする。PR のボタンはなくす。
- PR があるとき、状況パネルのボタンの角に CI の点と PR の数を出す。PR のボタンに載せていたマージの印 (マージ中は青の回転、失敗は赤の ! と赤枠) もこのボタンに載せる。
- 状況パネルの先頭、タブの上に PR の一覧を置く。今までの PR のシートと同じ行で、マージできる行に Merge、マージできない行に理由を出す。
- ヘッダーの高さは変えない。PC は変えない。

## 理由

- ☰ を足してもタイトルが読める。PR のボタンのぶん幅が空き、1 行で切っていたときより多くの文字が出る。
- タイトルの行を足さないので、会話に使える高さが減らない。
- 状況パネルの入口はボタンのまま残り、CI とマージの状態もヘッダーで分かる。PR を開くのはパネルを経るぶん 1 回多くなる。
