# 止められた操作のカードを許可せずに片付ける

auto mode が止めた操作のカード (Operation denied) には、コマンドと理由が出る。判定のある拒否には Allow and retry のボタンも出る。許可するまで会話の一番下に残り続けていた。

## 案

- A: Allow and retry の隣に Dismiss のボタンを置く。押すと 1 行にたたむ。
- B: カードの見出しの行の右端に × を置く。押すと A と同じ 1 行にたたむ。
- C: Allow and retry の隣に Don't allow のボタンを置く。押すとカードはそのままの大きさで灰色になり、「Not allowed · 時刻」を出す。

## 採用した案

A。PC とスマホの両方で、Allow and retry の隣に Dismiss のボタンを置く。スマホのボタンの文字は 12px にする。Dismiss を押すと、カードは会話の一番下から外れて、起きた時刻の位置に「Operation denied · Dismissed <コマンド> ▸」の灰色の 1 行で残る。1 行を押すとカードが開く。

## 理由

- 片付けたあとは 1 行しか場所を取らない。
- ボタンの名前で、押すと何が起きるかが分かる。
- 1 行を開けば、何を止められたかを確かめられる。
- B の × は、拒否なのか隠すだけなのかが分からない。スマホでは 44px の × が見出しの行を狭める。
- C は片付けたあとも場所を取り続ける。セッションに「許可しない」と伝えるように読める。
