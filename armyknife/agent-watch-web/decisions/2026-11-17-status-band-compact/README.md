# 返信欄の上の帯を小さくする

返信欄の上の帯は、どの状態でも 2 行で、スマホでは約 90px を取っていた。実行中や要約中のように見るべきことが少ない状態でも、会話がそのぶん短くなる。すぐ見るべきなのは crit のレビュー待ちだけで、質問と permission は答える操作が会話の中のカードにあり、帯は同じ文を繰り返しているだけだった。

## 案

- current: 今の帯。どの状態も 1 行目が状態、2 行目が詳細の 2 行。
- A: 状態と詳細を 1 行にまとめた帯。押すと詳細を全部出す。crit のレビュー待ちだけ今の帯。
- B: crit のレビュー待ちのときだけ帯を出し、ほかの状態は返信欄の下の使用状況の行の先頭に小さく出す。
- C: 返信欄の左上の枠線に乗るチップにし、押すと詳細を吹き出しで出す。crit のレビュー待ちだけ今の帯。

## 採用した案

A。crit のレビュー待ち以外は、状態と詳細を 1 行にまとめ、はみ出た詳細は … で切る。高さはデスクトップで 32px、スマホで 44px。行全体がボタンで、押すと詳細を全部出す (バックグラウンドタスクは全部のタスクを出す)。質問と permission は文字も黄色にし、末尾の ↑ を押すと会話の中のカードに戻る。状態の文は Compacting…、Background tasks (2)、Question、Permission に短くする。crit のレビュー待ちは、バックグラウンドタスクと重なるときも含めて、今の 2 行の帯と Review in crit のボタンのまま残す。

## 理由

- A は帯の場所も見た目も今と同じで覚え直しがなく、見るべきことが少ない状態の高さを半分にできる。
- B は帯がなくなるぶん最も低いが、文字が小さく返信欄より下にあるので、質問と permission に気づきにくい。
- C は返信欄の一部に見えて場所を取らないが、チップの幅が狭く詳細が A より早く切れ、押せる範囲の半分が会話欄にはみ出す。
