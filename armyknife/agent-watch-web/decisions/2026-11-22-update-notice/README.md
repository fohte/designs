# 新しいバージョンの通知

サーバーが再起動すると、画面は instance id が変わったのを見てすぐ再読み込みしていた。返信欄に打ちかけた文章はその場で消えていた。

どの案でも次のことは決まっている。自動では再読み込みしない。新しいバージョンがあるときだけ通知し、Reload を押すと再読み込みする。× で閉じると次の更新まで出さない。新しいバージョンのない再起動では何も出さない。

## 案

- A: ヘッダーの小さなボタン。PC は Nav のロゴの下に 1 行、iPhone は見出しの中に出す。
- B: 一番上の全幅の帯。PC は画面全体の一番上に高さ 36px、iPhone はヘッダーのすぐ下に 52px の帯で、New version v0.4.2 is ready. と Reload、× を出す。
- C: Activity の toast と同じ場所に残るカード。PC は右下、iPhone は返信欄の上に出す。

## 採用した案

B。

## 理由

- 画面のどこを見ていても目に入り、見落としにくい。
- toast は下、帯は上に分かれ、重ならない。
- 帯が出た瞬間に画面全体が帯の高さ (PC は 36px、iPhone は 52px) だけ下にずれることは受け入れる。
