# iPhone の Inbox の行の操作と絞り込み

PC の Inbox はキーボードで行を Later に回し (L)、閉じ (e)、/ で絞り込める。iPhone の Inbox にはどれもなく、行を開いて会話の ⋯ から操作するしかなかった。絞り込みも「Filter by … /」の小さい文字があるだけで、押しても何も起きなかった。

問いは 2 つで、それぞれ案を比べた。

## 行の操作

- 左にスワイプ: 行の中で左にスワイプすると、右に Later と赤い Close が出る。
- 長押しのシート: 行を長押しすると、Later と赤い Close session… のシートが出る。

どちらの案も、Later は PC の Later メニューと同じ選択肢を下からのシートで出し、Close は Done 以外なら PC の e と同じ文言の確認シートを出す。

スワイプと長押しの両方を入れることにした。

- スワイプは iOS のメールと同じ操作で、行を開かずに次々と片づけられる。
- 長押しのシートは会話の ⋯ メニューと同じ並びで、スワイプを知らなくても見つけやすい。操作を後から足す場所にもなる。
- 画面の端からのスワイプはブラウザの戻る操作に取られるので、行の中のスワイプにした。横スクロールする Starred の帯や戻る操作と混ざらないかは、まだ実機で確かめていない。

## 絞り込み

- PC の / と同じ入力欄: 見出しの下に絞り込みの欄を常に置き、押すと全画面に切り替わる。PC と同じ書き方 (project:web-app kind:review) で打て、上のタブで項目、チェックで値も選べる。絞り込んだ状態は PC と同じチップで出す。
- 項目ごとのボタン: Project、Kind などのボタンを横に並べ、押すとその項目の値をシートでチェックする。

PC の / と同じ入力欄を選んだ。

- PC と同じ書き方とチップで、覚えることが PC と変わらない。
- task:#123 のような文字での絞り込みができる。項目ごとのボタンではできず、値が多いとシートに検索欄も要る。
- 欄を押すと画面全体が切り替わり、キーボードが値の一覧の下半分を隠すことは受け入れる。
- 一番上に 44px の欄が常に増えることは受け入れる。
