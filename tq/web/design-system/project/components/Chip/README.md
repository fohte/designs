# Chip

A short bordered mono label from `@fohte/ui/chip`, used for tags, counts and small states.

- The consumer supplies the text, `size` (`sm` default, `md`), `tone` (`muted` default, `strong`, `faint`) and, for a removable chip, `onRemove` with a `removeLabel`.
- Text is `text-2xs` mono; the border is `border`, or `border-strong` for `strong`.
- A chip rendered as a button is clickable and cannot be removable.
